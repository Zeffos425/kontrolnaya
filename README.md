# Music Streaming — База данных музыкального стриминга

Реляционная база данных для платформы музыкального стриминга, реализованная на **Microsoft SQL Server (SSMS)**.

## Описание

Проект представляет собой схему базы данных для музыкального стриминг-сервиса. База данных хранит информацию о:

- Пользователях и их ролях
- Артистах
- Треках и жанрах
- Альбомах и лейблах
- Плейлистах
- Истории прослушиваний
---

## Технологии

- **Microsoft SQL Server**
- **SSMS** (SQL Server Management Studio)
- **T-SQL**
- **DRAW.IO**

---

## Структура базы данных

| Таблица | Описание |
|---------|----------|
| `roles` | Роли пользователей (admin, user, artist) |
| `labels` | Музыкальные лейблы |
| `genres` | Жанры музыки |
| `users` | Пользователи системы |
| `artists` | Артисты (связаны с пользователями) |
| `tracks` | Музыкальные треки |
| `albums` | Альбомы |
| `album_tracks` | Связь альбомов и треков (many-to-many) |
| `playlists` | Плейлисты пользователей |
| `playlist_tracks` | Связь плейлистов и треков (many-to-many) |
| `listenings` | История прослушиваний |
